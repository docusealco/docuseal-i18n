# 🌍 DocuSeal I18n

Translations for the [DocuSeal](https://www.docuseal.com) open-source e-signature platform. See [Languages Support](https://www.docuseal.com/resources/languages-support) for more details.

This repository mirrors the translation files from the main [DocuSeal](https://github.com/docusealco/docuseal) project to make it easier to contribute, review, and improve translations via pull requests.
